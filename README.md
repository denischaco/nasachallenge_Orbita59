# Órbita 59

Prototipo inicial de la experiencia interactiva de Órbita 59, un cuento para descubrir historias y tecnología relacionadas con Marte.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```

Al entrar aparece un diálogo de preparación con la música desactivada por defecto y una recomendación de pantalla grande. La música se habilita únicamente si la persona la activa; hasta contar con la banda sonora original se usa un ambiente sonoro sintético muy suave.
